# Gunapu Sahithi: Portfolio

Static portfolio website (HTML + CSS). No build step needed.

## Files
- `index.html`: page content
- `styles.css`: styling (light/dark theme, responsive)
- `images/profile.jpg`: profile photo

## Deploy on GitHub Pages
1. Create a public repo named `Sahithi3005.github.io`
2. Upload all files (keep the `images` folder)
3. Settings > Pages > Deploy from branch > `main` / root
4. Live at https://sahithi3005.github.io
